| 维度 | 内容 |
| --- | --- |

| API 前缀 | `EDS` |

设计理念（README 提炼）：

1. **调用方描述"这是什么"**：`.easyDesign(.card)` 只声明语义，系统负责映射 padding、背景、圆角、边框、阴影。
2. **两层 API 并行**：Easy API 管整体层级（Page/Section/Group/Card），精细 API 提供组件与 Token。
3. **不默认填色**：Page/Content/Section/Plain 继承宿主背景，Group/Card 才绘制语义表面。
4. **Easy API 只作用于组合容器**：按钮的危险/主要等含义由调用方通过 `EDSButton(role:)` 显式声明。

## 3. Token 层（EDSDesignTokens.swift，570 行）

9 组子 Token，全部 `Codable + Equatable + Sendable`，自定义解码**字段缺失时回退默认值**：

| Token | 字段（默认值） | 备注 |
| --- | --- | --- |
| `EDSColorTokens` | primary/accent(#蓝)、success(#绿)、warning(#橙)、danger(#红) | JSON 存 hex 字符串；派生色 `accentSoft` 等 = 12% 透明；`textPrimary/textSecondary` = 系统语义色；`pageBackground/cardBackground` 平台分支（macOS windowBackground/controlBackground，iOS systemBackground/secondarySystemBackground） |
| `EDSSpacingTokens` | xxs=4 … xxxl=40（8 档） | |
| `EDSRadiusTokens` | sm=8 / md=12 / lg=16 / xl=24 | |
| `EDSTypographyTokens` | hero/pageTitle/sectionTitle/body15/body15Strong/body/bodyStrong/caption/captionStrong/monoCaption 各含 size+weight 字符串 | 运行时生成 `Font`；weight 字符串 → `Font.Weight`；hero/pageTitle 用 `.rounded` design，monoCaption 用 `.monospaced` |
| `EDSControlSizeTokens` | buttonHeight=34 / fieldHeight=34 / rowMinHeight=52 | |
| `EDSAdaptiveLayoutTokens` | compactPagePadding=16 / regularPagePadding=32 / readableContentMaxWidth=880 / minimumTouchTarget=44 / minimumHybridTarget=44 | |
| `EDSHeroGradient` | startColor/endColor | 渐变方向 topLeading → bottomTrailing；内置 blue/orange/purple 三组预设 |
| `EDSStrokeTokens` | hairline=1 | |
| `EDSShadowTokens` | color="#000000" / opacity=0.06 / radius=18 / x=0 / y=10 | 预设 card/subtle/prominent |

`Color` 扩展：`hexRGB`（#RGB/#RRGGBB）、`hexARGB`（#AARRGGBB）、`hexRGBA`（#RRGGBBAA）、`toHex()`（经平台桥接解析动态色后输出 #RRGGBB）。**注意**：`toHex` 依赖 AppKit/UIKit 解析，动态系统色按浅色外观取值。

## 4. 主题层（EDSTheme.swift + EDSThemeEnvironment.swift）

- **全局**：`EDSTheme.shared` 单例，NSLock 保护的值拷贝读写；启动期配置（`configure{}`、`configure(jsonData:)`、`configure(jsonFileURL:)`、`configure(jsonResource:)`、`applyPreset(_:)`），导出（`exportJSON()` / `exportJSONString()`，prettyPrinted + sortedKeys）。**V1 不承诺运行时改全局主题自动刷新 UI**。
- **局部**：`@Environment(\.edsTheme)`，EnvironmentKey 默认值 `nil`，读取时惰性回退 `EDSTheme.shared.tokens`（保证启动期配置不被静态 key 冻结）。注入用 `.easyDesignTheme(tokens/preset)`，不改变布局。
- **预设**：`EDSPresetTheme`（id/name/tokens），内置 `.default`（蓝，= `.blue` 别名）、`.orange`、`.purple`，`allPresets` 数组。预设显式补齐语义色 hex（#27B15A / #F9B135 / #E54444 等）与配套 Hero 渐变。

## 5. Easy API（EDSEasyDesign.swift，369 行）

- 六种语义场景 `EDSEasyStyle`：`page / content / section / group / card / plain`。
- 三个高频覆盖维度（`EDSEasyOptions`）：
  - `padding: EDSSpace`（automatic/none/xxs…xxxl，语义间距查 spacing 表）
  - `maxContentWidth: EDSEasyWidth`（automatic / fixed(CGFloat) / unlimited）
  - `background: EDSEasyVisibility`（automatic / visible / hidden）
- **`EDSEasyRecipe` 纯函数**（核心可测单元）：`(style, options, tokens, profile, sizeClass) → padding/paddingAxis/width/background/cornerRadius/showsBorder/showsShadow`。六场景基线配方：

| 场景 | padding | 轴 | 宽度 | 背景 | 圆角 | 边框 | 阴影 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| page | pagePadding(自适应) | all | fixed(880) 居中 | 继承 | 0 | 无 | 无 |
| content | spacing.md | all | fill | 继承 | 0 | 无 | 无 |
| section | spacing.xs | vertical | fill | 继承 | 0 | 无 | 无 |
| group | spacing.lg | all | fill | subtle | radius.md | 无 | 无 |
| card | spacing.lg | all | fill | card | radius.md | 有 | 有 |
| plain | 0 | all | unchanged | 继承 | 0 | 无 | 无 |

  覆盖规则：显式 padding 强制 axis=.all；`maxContentWidth: .fixed` 负数夹取为 0；`background: .visible` 仅在原为继承时升级为 page 背景，`.hidden` 强制继承。
- 修饰器行为链：padding → width → surface → 重注入 theme 环境 → tint(accent) → 默认字体(.body) → 前景色(textPrimary)。
- 三个重载：`easyDesign(style:options:)`、`easyDesign(style:theme:options:)`（预设主题作用域）、`easyDesign(style:tokens:options:)`（自定义 Token 作用域）。

## 6. 自适应层（EDSAdaptiveEnvironment.swift）

- `EDSInteractionProfile`：`automatic`（默认，按平台解析：macOS→pointer、Catalyst→hybrid、其余→touch）/ `touch` / `pointer` / `hybrid`；`.easyDesignInteractionProfile()` 覆盖子树。
- `EDSResolvedMetrics.resolve(tokens:profile:horizontalSizeClass:)`：
  - `pagePadding`：compact→compactPagePadding（未显式配置时回退 spacing.md），regular→regularPagePadding（回退 spacing.xxl）
  - `minimumInteractiveDimension`：touch/hybrid→44，pointer→0（用 `interactiveHeight(for:)` 给行高兜底）
  - `supportsHoverEnhancement`：非 touch；`showsPersistentAuxiliaryActions`：非 pointer（决定 Pill 删除按钮常显）
- 组件大量读取 `horizontalSizeClass` 和 `dynamicTypeSize`（辅助功能特大字体时 Row 切竖排）。

## 7. 字体系统（EDSScaledTypography.swift + EDSDesignTokens 字体工厂）

- 双实现：Token 直接生成固定 size 的 `Font`（`.system(size:weight:design:)`）；`EDSFontRole`（hero/pageTitle/sectionTitle/body15/body15Strong/body/bodyStrong/caption/captionStrong/monoCaption）→ 映射系统 TextStyle（largeTitle/headline/subheadline/body/caption/caption2）+ weight + design，随动态字体缩放。组件统一通过 `.edsFont(role, tokens:)` 调用。

## 8. 渲染原语与平台桥接

- `EDSSurfaceConfiguration`（background/AnyShapeStyle?、cornerRadius、borderColor?/borderWidth、shadow?）→ `.edsSurface()` 修饰器：RoundedRectangle(continuous) 填充 + 可选描边 + 可选阴影；`colorSchemeContrast == .increased` 时强制 1.5pt 边框（无障碍高对比度）。
- `EDSPlatformColorBridge`：macOS 用 NSColor(sRGB, aqua 外观)、iOS 用 UIColor(light trait) 解析动态色转 hex；macOS 侧保留 `NSImage` 旧初始化方法。

## 10. 测试与质量基建

单元测试 13 个，关键契约：

1. 公开入口全部可编译构造（含 README 示例页）。
2. 部分 JSON 字段缺失回退默认值（partial JSON）。
3. hex 三格式语义（RGB/ARGB/RGBA）与 round-trip。
4. 主题色编码 round-trip 不静默变黑。
5. 动态背景色解析非 #000000。
6. 预设清单与 id 顺序（default/orange/purple）。
7. 环境局部 Token 优先于全局单例。
8. 六场景 Recipe 逐项断言。
9. Options 覆盖（padding .none、fixed(-10)→0、background hidden）。
10. 三份 Fixture JSON（Legacy/PartialLegacy/MultiplatformTheme）解码契约，含自适应字段。
11. 三种交互档案的 metrics 解析（touch/pointer/hybrid × compact/regular）。
12. 显式 adaptiveLayout padding 覆盖回退逻辑。
13. `.done` role = filled+success+regular（回归锁）与四个旧 role 外观不变。

基建：`Tests/APICompatibility/EasyDesignSystem-PublicAPI.txt` 公开 API 基线 + `Scripts/check-api-compatibility.sh`（防破坏性变更）；`validate-platform-builds.sh` 四平台构建；`run-ui-tests.sh`。

## 12. 迁移关注点提炼（Flutter 侧必须回答的问题）

| # | 关注点 | 现状 | 迁移含义 |
| --- | --- | --- | --- |
| 1 | SF Symbols | 图标全部 `Image(systemName:)`（chevron、xmark、checkmark、tray 等） | Flutter 无 SF Symbols；需 IconData 参数化 + 图标策略 |
| 2 | 系统语义色 | pageBackground 等走 NSColor/UIColor 动态色 | Flutter 需自带 light/dark 语义色对 |
| 3 | 主题双通道 | 全局单例（非响应式）+ Environment（响应式） | Flutter InheritedWidget 天然响应式，可考虑支持运行时全局切换 |
| 4 | ViewModifier 链 | `.easyDesign()` 修饰器 + 环境 | Flutter 无修饰器；需要 Widget 包装 + Widget 扩展方法模拟调用形态 |
| 5 | `EDSFlowLayout` | 自研 Layout 协议换行 | Flutter `Wrap` 原生等价 |
| 6 | LocalizedStringKey | 大量组件文案走本地化 key | Flutter 组件收 String，本地化交给宿主 App |
| 7 | Bundle 资源 | EDSDefaultTheme.json、Localizable.strings | Flutter 资源声明方式不同（package assets / 宿主 assets） |
| 8 | `EDSSection` | 包装 SwiftUI List 的 `Section` | Flutter 无直接等价物，需重新定义（普通分组容器或 Sliver 方案） |
| 9 | Continuous 圆角 / Capsule | `RoundedRectangle(style: .continuous)`、`Capsule` | Flutter 圆角为普通 quadratic；Capsule 用 StadiumBorder/充分大半径 |
| 10 | 无障碍 | reduceMotion、differentiateWithoutColor、colorSchemeContrast、Dynamic Type、accessibility label/trait | Flutter 对应 MediaQuery.disableAnimations、Semantics、textScaler、高对比度需另评估 |
| 11 | Font design `.rounded` / `.monospaced` | hero/pageTitle rounded、monoCaption monospaced | Flutter 无 rounded design；等宽可用 fontFamily(fallback) |
| 12 | hover / 按压反馈 | onHover 透明度、scaleEffect 按压 | Flutter MouseRegion + Listener/AnimatedScale |
| 13 | toHex 动态色解析 | 依赖 AppKit/UIKit 解析当前色值 | Flutter 颜色为具体值，可直接转换；亮暗分别取值需约定 |
| 14 | 公开 API 基线 | 文本基线 + 脚本检查 | Dart 侧可先以测试固化关键签名，公开 API diff 工具另议 |
| 15 | 运行环境 | 目标本机 Flutter SDK 为 OpenHarmony SIG fork（3.41.10-ohos） | 纯 Dart 包可同时覆盖 Android/iOS/macOS/Windows/Linux/Web/OHOS |

## 13. 结论

Swift 包结构清晰、分层明确、可测性好：**Token 纯值 + Recipe 纯函数 + 组件薄壳**的模式可以几乎原样移植到 Flutter/Dart；主要工作量集中在四件事——(1) 语义色的亮暗对与 hex 工具；(2) Environment → InheritedWidget 的主题机制重设计；(3) 约 30 个组件的 Flutter 重写（含无障碍与交互反馈）；(4) 图标与本地化两处 Apple 依赖的替换策略。
