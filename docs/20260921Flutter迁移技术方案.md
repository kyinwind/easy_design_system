## 1. 目标与非目标

### 1.1 目标

1. 在 Flutter 中复刻 EasyDesignSystem 的**设计语义**：Token 体系、两层 API（Easy API + 精细 API）、六种语义场景、三组预设主题。
2. **JSON 主题格式与 Swift 版完全兼容**：`EDSDefaultTheme.json`、既有主题 JSON、三份测试 Fixture 可直接复用；导出的 JSON 可回灌 Swift 版。
3. 组件名与语义一一对应：`EDSButton` → `EdsButton`，`EDSSettingRow` → `EdsSettingRow`……业务页面从 SwiftUI 迁到 Flutter 时心智模型不变。
4. 多平台一致：同一份 Dart 代码运行于 Android / iOS / macOS / Windows / Linux / Web / OHOS（本机 SDK 即 ohos fork），交互档案自动适配。
5. 测试契约与 Swift 版一一对应：13 个单测逐条移植，固化 Recipe、hex、预设、自适应等关键行为。

### 1.2 非目标（V1 明确不做）

- 不做像素级还原（SwiftUI 与 Flutter 渲染细节天然不同，如 continuous 圆角、字体渲染）。
- 不做 SF Symbols 兼容层（图标策略见 §9）。
- 不做运行时 JSON 热重载编辑器以外的设计工具（Catalog 的 Token 编辑器保留，见 §11）。
- 不承诺与 Swift 版二进制/视觉逐像素一致，只承诺**语义一致**。

## 2. 包形态决策

| 决策点 | 结论 | 理由 |
| --- | --- | --- |
| plugin vs package | **纯 Dart Flutter package**（无 platform channel） | 设计系统只依赖框架层能力；Swift 版的平台桥接（hex 解析）在 Dart 中是纯计算；纯 Dart 天然覆盖全部目标平台（含 OHOS） |
| 包名（pub.dev） | `easy_design_system`；仓库名/目录名保持 `flutter_easy_design_system` | pub.dev 官方不建议社区包使用 `flutter_` 前缀（易与官方包混淆）；目录名不变，仅 `pubspec.yaml` 中 `name: easy_design_system` |
| 依赖 | 仅 `flutter`（SDK），无三方运行时依赖 | 设计系统应保持零依赖；不引入 provider/riverpod，主题机制用 InheritedWidget 自建（见 §5） |
| Material/Cupertino | 组件内部按需使用 Material 基础件（`Switch`、`InkWell` 等），`uses-material-design: true` | Material 基础件在所有平台可用且可定制；Cupertino 视觉差异交给主题色而非组件分叉 |
| 最低 SDK | Dart SDK `^3.5`，Flutter `>=3.24` | 覆盖主流稳定版；本机 3.41 满足 |

## 5. 主题机制设计

### 5.1 Token 模型

`EdsDesignTokens` 为**不可变类**（Dart 惯例），9 组子 Token 与 Swift 字段名一致（驼峰保留：`heroSize`、`pageTitleWeight`……保证 JSON key 逐字节一致）：

- 修改走 `copyWith`；提供与 Swift 各子结构对应的 `EdsColorTokens`、`EdsSpacingTokens`……独立类。
- `EdsTheme.instance.update((t) => t.copyWith(spacing: t.spacing.copyWith(md: 18)))` 对应 Swift 的 `configure { $0.spacing.md = 18 }`。
- `==`/`hashCode`/`toString` 全实现（InheritedWidget 更新判定依赖 `==`）。

### 5.2 语义色与亮暗模式（Swift 差异最大的部分）

Swift 依赖系统动态色；Flutter 侧由 `EdsColorScheme.resolve(tokens, brightness)` 纯函数解析出全部派生色：

| 派生色 | light | dark | 对应 Swift |
| --- | --- | --- | --- |
| textPrimary | `#000000`（opacity 0.9） | `#FFFFFF`（opacity 0.9） | Color.primary |
| textSecondary | black 0.6 | white 0.6 | Color.secondary |
| textTertiary | black 0.43 | white 0.43 | secondary.opacity(0.72) |
| pageBackground | `#F7F7F7` | `#1E1E20` | windowBackground/systemBackground |
| cardBackground | `#FFFFFF` | `#2A2A2C` | controlBackground/secondarySystemBackground |
| cardGrayBackground | black 0.045 | white 0.045 | 原样 |
| subtleFill | black 0.03 | white 0.03 | 原样 |
| border | black 0.10 | white 0.10 | 原样 |
| accentSoft / successSoft / … | 各语义色 12% 透明（不分亮暗） | 同 | 原样 |

- Brightness 来源：`EdsThemeScope` 注入 > `MediaQuery.platformBrightness`；`EdsApp` 便捷根组件（内部 `MaterialApp` 可选）统一接线。
- `toHex()`：对具体 Color 直接换算；文档明确"导出的是当前亮度的具体色值"（与 Swift 按浅色外观解析行为对齐）。
- 亮暗数值为 V1 默认值，集中在一处常量便于后续调优。

### 5.3 全局主题与运行时切换（对 Swift 的增强项）

- Swift V1 明确"运行时改全局主题不自动刷新"。Flutter 的 InheritedWidget 方案下，`EdsThemeScope` 顶部包一次即可获得全局响应式刷新：**建议** `EdsTheme.instance` 内部持 `ValueNotifier<EdsDesignTokens>`，`EdsThemeScope` 未显式传 tokens 时自动订阅全局。
- 保持 Swift 兼容语义：局部显式 tokens 恒优先于全局；组件读取统一走 `context.edsTokens`。
- Catalog 的主题切换器依赖此能力。

## 6. Easy API 设计

### 6.1 类型与 Recipe（与 Swift 一一对应）

```dart
enum EdsStyle { page, content, section, group, card, plain }
enum EdsSpace { automatic, none, xxs, xs, sm, md, lg, xl, xxl, xxxl }
sealed class EdsWidth { automatic; fixed(double); unlimited }        // 参数化枚举
enum EdsVisibility { automatic, visible, hidden }
class EdsOptions { padding; maxContentWidth; background }            // 默认全 automatic

@immutable
class EdsEasyRecipe {
  final double padding;
  final EdsPaddingAxis paddingAxis;
  final EdsResolvedWidth width;
  final EdsBackgroundPolicy background;
  final double cornerRadius;
  final bool showsBorder;
  final bool showsShadow;

  static EdsEasyRecipe resolve({
    required EdsStyle style,
    EdsOptions options = const EdsOptions(),
    required EdsDesignTokens tokens,
    EdsInteractionProfile profile = EdsInteractionProfile.automatic,
    EdsSizeClass sizeClass = EdsSizeClass.regular,
  });
}
```

六场景基线配方、options 覆盖规则（padding 强制 all 轴、fixed 负数夹 0、visible 仅升级 inherited→page、hidden 强制 inherited）**逐条移植**，由测试固化。

### 6.2 EdsEasy Widget 行为链

`padding → width → surface → 主题环境重注入 → tint/默认字体/前景色` 对应实现：

- padding/width：`Padding` + `ConstrainedBox`/`Align`（fixed 用 maxWidth + 居中，fill 用 `double.infinity` 对齐 leading）。
- surface：`EdsSurface`（§8）。
- 环境重注入：`EdsThemeScope(tokens: resolved, child: ...)`。
- 默认字体/前景：`DefaultTextStyle` + `IconTheme` 覆盖。

### 6.3 调用形态（Widget 扩展模拟修饰器）

```dart
// 核心 Widget（规范入口）
EdsEasy(style: EdsStyle.card, child: content)

// 扩展（调用形态贴近 Swift）
content.easyDesign()                        // .page
content.easyDesign(EdsStyle.group)
content.easyDesign(EdsStyle.section, options: EdsOptions(padding: EdsSpace.xl))
content.easyDesign(EdsStyle.card, theme: EdsPresetTheme.orange)

// 仅主题不布局
child.easyDesignTheme(tokens)
```

扩展实现为 `EdsEasy` 的薄包装；文档同时给出两种写法，扩展为语法糖。

## 7. 自适应设计

### 7.1 交互档案

```dart
enum EdsInteractionProfile { automatic, touch, pointer, hybrid }
```

`automatic` 解析规则（`defaultTargetPlatform` + `kIsWeb`）：

| 环境 | 解析结果 | 对应 Swift |
| --- | --- | --- |
| iOS / Android / Fuchsia | touch | iOS 分支 |
| macOS / Windows / Linux | pointer | macOS 分支 |
| Web（桌面浏览器） | hybrid | Catalyst 分支 |
| Web（移动浏览器） | touch | — |
| OHOS | touch | —（Flutter 特有） |

覆盖入口：`EdsInteractionProfileScope` 或 `MediaQuery` 扩展；`EdsInteractionProfile.of(context)`。

### 7.2 尺寸档位

`EdsSizeClass { compact, regular }`：以 `MediaQuery` 宽度 **600 逻辑像素** 为断点（对齐 Apple hSizeClass 常规取值与 Material 窗口规范）；`EdsSizeClass.of(context)`。

### 7.3 度量解析与无障碍字体

`EdsResolvedMetrics.resolve(tokens, profile, sizeClass)` 字段与 Swift 完全一致（pagePadding 回退逻辑：compact→spacing.md、regular→spacing.xxl，显式 adaptiveLayout 值优先；touch/hybrid 44 触控目标；pointer 0；hover/persistent 辅助动作开关）。

- `interactiveHeight(for:)` → `interactiveHeight(double visualHeight)`。
- `isAccessibilitySize`：`MediaQuery.textScaler.scale(1.0) >= 1.7` 时 Row 类组件切竖排（对齐 Swift 的 `dynamicTypeSize.isAccessibilitySize` 意图；阈值写入常量可调）。

## 8. 渲染原语

`EdsSurface`（内部 `DecoratedBox`）+ `EdsSurfaceConfiguration`：

```dart
class EdsSurfaceConfiguration {
  final Decoration? background;   // 对应 AnyShapeStyle?
  final double cornerRadius;
  final Color? borderColor;
  final double borderWidth;
  final EdsShadowTokens? shadow;
}
```

- 圆角用 `BoxDecoration(borderRadius:)`；描边用 `Border.all`；阴影直接映射 `BoxShadow`（color=shadow.shadowColor、blurRadius=radius、offset=(x,y)）。
- background 为 null 时原样返回 child（与 Swift 一致）。
- V1 不实现高对比度强制边框（差异报告记录）。

`EdsFontRole`（10 档）→ `TextStyle` 工厂：`tokens.typography.textStyle(role, {Brightness?})`；weight 字符串 → `FontWeight` 映射表与 Swift 相同（bold/sedemibold/medium/regular/light/thin，未知→regular）：

| Role | fontSize 来源 | fontWeight 来源 | 备注 |
| --- | --- | --- | --- |
| hero / pageTitle | heroSize / pageTitleSize | 各自 weight | Swift 的 `.rounded` design 无 Flutter 等价，差异报告记录 |
| sectionTitle…captionStrong | 对应 size | 对应 weight | |
| monoCaption | monoCaptionSize | 对应 weight | `fontFamily: 'monospace'` + `fontFamilyFallback`（命中平台等宽字体） |

`Widget edsFont(EdsFontRole role)` 扩展 → `DefaultTextStyle.merge`。

## 9. 图标策略（替代 SF Symbols）

1. **组件 API 收 `IconData`**（可选参数），不收 symbol 名字符串：`EdsButton('确定', icon: Icons.check)`、`EdsEmptyState(icon: Icons.inbox)`、`EdsSidebarIcon(icon: ..., tint: ...)`。
2. **不设默认图标**：Swift 中 `.done` 自动补 checkmark 的行为保留为 `EdsButtonRole.done` 默认 `Icons.check_mark`（Material）；其余组件 icon 为 null 时不渲染图标。
3. Catalog 与文档提供 **常用符号映射参考**（tray→inbox、chevron.right→chevron_right、xmark.circle.fill→cancel、exclamationmark.triangle→warning、arrow.clockwise→refresh、checkmark.circle.fill→check_circle、minus.circle→remove_circle_outline 等）。
4. iOS/macOS 上宿主 App 想用 SF Symbols 可通过自定义 IconData/cuperticons 三方包自行接入，本包不依赖。

## 10. 本地化与文案

- 所有组件文案参数收 `String`（不引入 intl/arb 依赖），本地化交给宿主（Flutter 惯例：App 层做 intl，组件层收纯文本）。
- Swift 的 `EDSComparisonSection` 内置 Bundle 文案（"功能/免费/专业版"）改为**构造参数**：`EdsComparisonSection(features: [...], freeLabel: '免费', proLabel: '专业版', featuresLabel: '功能')`，默认值用中文（与 Swift zh-Hans 基线一致）。
- 不内置 .lproj/.arb 资源。

## 13. 与 Swift 版 API 差异报告（摘要）

| 差异 | 原因 | 兼容策略 |
| --- | --- | --- |
| `.easyDesign()` 修饰器 → Widget + 扩展 | Flutter 无修饰器 | 扩展保留调用形态 |
| `configure { inout }` → `update((t) => copyWith)` | Dart 无 inout | 文档对照示例 |
| 图标：symbol 名 → `IconData?` | 无 SF Symbols | §9 映射表 |
| 文案：`LocalizedStringKey` → `String` | 本地化策略 | §10 |
| 语义色亮暗：系统动态色 → 内置亮暗表 | 无 NSColor/UIColor | 常量集中可调 |
| `.rounded` 字体设计缺失 | Flutter 无 | 视觉差异，记录 |
